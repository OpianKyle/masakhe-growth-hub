8) SCHEDULER / PUBLISHING ENGINE

Create a background worker that runs every minute:

fetch SocialPosts with status SCHEDULED and scheduledAt <= now

mark as PUBLISHING

publish to each SocialPostTarget using platform provider

update target status + platformPostId

if all targets succeed: SocialPost => PUBLISHED

if any fail: SocialPost => FAILED (but keep per-target statuses)

write AuditLog entries

Must be resilient:

avoid double posting (idempotency key per target)

retries for transient failures (max 3 with backoff)

store failure reason
