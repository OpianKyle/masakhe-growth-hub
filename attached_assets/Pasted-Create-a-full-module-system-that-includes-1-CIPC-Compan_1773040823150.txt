FEATURE 1: CIPC COMPANY VERIFICATION

Create a page called "Verify Company".

User inputs:
- CIPC Registration Number

System will call the CIPC Companies API and retrieve:

- Business Name
- Registration Number
- Company Type
- Registration Date
- Company Status
- Directors
- Registered Address
- Financial Year End

Display the data in a company profile card.

Add:
"Verified by CIPC" badge if the company exists.

Save the company profile to database table:
companies

Fields:

id
user_id
company_name
registration_number
company_type
registration_date
status
directors
address
financial_year_end
created_at

Allow users to select this company profile when creating documents.
