Step 1 - Get oAuth Credentials
{{Host}}/oauth/token?grant_type=client_credentials&client_id={{ClientID}}&client_secret={{ClientSecret}}
This API endpoint is used to obtain an access token for client authentication. It is an HTTP POST request that is sent to the /oauth/token endpoint with the required parameters.

To make a successful request, you need to provide the following parameters in the request URL:

grant_type: The type of grant being requested. In this case, it should be set to client_credentials.
client_id: The client ID of the application making the request. This is a required parameter.
client_secret: The client secret associated with the client ID. This is also a required parameter.
Once the request is made, the server will validate the client credentials and return a response with the access token.

The response will contain the following information:

access_token: The access token that can be used to authenticate subsequent requests.
token_type: The type of token returned. In this case, it will be Bearer.
expires_in: The expiration time of the access token in seconds.
scope: The scope of the access token, indicating the permissions granted to the client.
Please note that the client credentials should be kept secure and not shared with unauthorized parties.

Example Request:

Plain Text
POST {{Host}}/oauth/token?grant_type=client_credentials&client_id={{ClientID}}&client_secret={{ClientSecret}}
Example Response:

Plain Text
{
  "access_token": "{{vault:json-web-token}}",
  "token_type": "Bearer",
  "expires_in": 3600,
  "scope": "read write"
}

Step 5 - Refund card transaction
{{Host}}/products/payments/v1/card/refund
This endpoint allows you to initiate a refund for a payment made using a card. The refund amount should be specified in the request.

To initiate a refund, send an HTTP POST request to the following endpoint: {{Host}}/products/payments/v1/card/refund.

Request Parameters
None
Response Parameters
statusCode (integer): The status code of the refund request. Possible values include:

200: The refund request was successful.
Other status codes may indicate an error or a different state of the refund request.
transactionId (string): The unique identifier for the refund transaction. This value may be null if the refund request was not successful.
statusMessage (string): A message indicating the status of the refund request. This message will provide additional information about the refund request status.
eciFlag (string): The Electronic Commerce Indicator (ECI) flag for the refund transaction. This flag provides information about the type of transaction being processed.
authorisationCode (string): The authorization code for the refund transaction. This code is provided by the payment processor and indicates that the refund was approved.
processorResponse (string): The response code from the payment processor. This code provides additional information about the status of the refund transaction.
transactionState (string): The current state of the refund transaction. This value may be null if the refund request was not successful.
refundedAmount (integer): The amount that was refunded. This value will be the same as the refund amount specified in the request.
Example Response
JSON
{
