REVENUE LOGGER (MVP)
Add a new “Finance” section in the SME dashboard:

Tabs: “Income”, “Expenses”, “Monthly Summary”

Allow SME to add entries manually.

Data model:

Table: ledger_entries

id (uuid)

userId (fk)

type ("INCOME" | "EXPENSE")

amountCents (int)

category (string) // e.g. Sales, Transport, Rent, Stock, Utilities

description (string, optional)

occurredAt (date)

createdAt (date)

Backend:

CRUD endpoints:

POST /api/finance/entries

GET /api/finance/entries?month=YYYY-MM

DELETE /api/finance/entries/

Summary endpoint:

GET /api/finance/summary?from=YYYY-MM&to=YYYY-MM

returns totals per month + income/expense breakdown

Frontend:

Add “Finance” nav item

Add forms to create entries

Add table list with delete

Add a simple bar chart for monthly income vs expenses (Recharts)

COMPLIANCE SCORE (MVP, HIGH IMPACT)
Add “Compliance Score” card to the SME Overview page:

Score from 0–100 with a progress bar

Show checklist items and what’s missing

Scoring rules (simple + explainable):

POPIA consent completed: +10

Business profile completed (required fields present): +20

Website published: +20

At least 3 social drafts generated: +10

At least 1 invoice created: +20

At least 10 ledger entries logged: +20

Backend:

GET /api/compliance/score

Returns { score, items: [{key,label,points,completed}], nextSteps: [...] }

Frontend:

Show score + “Next Best Actions” list

Make each missing item link to the relevant page

GRANT READINESS CHECKLIST (MVP)
Create a “Funding Readiness” page for SMEs:

Checkbox checklist (some auto-checked based on data; some user-provided)

Show readiness % and a “Download Readiness Summary” button (PDF optional, can be v2)

Data model:

Table: grant_readiness

userId (pk)

idVerified (bool)

businessRegistered (bool)

taxNumber (string, optional)

vatRegistered (bool)

bankAccountProvided (bool)

sixMonthsRecords (bool)

createdAt, updatedAt

Backend:

GET /api/funding/readiness

POST /api/funding/readiness (upsert)

Frontend:

Page with sections:

Identity & Registration
